GO GAS – CATHRY & CABRYN ENTERPRISES
Android Studio starter project

Features:
- Offline local sales records
- Commercial 19.3 KG cylinder sales
- Price entered separately for each sale (supports changing prices)
- Customer name and mobile number
- Cash / UPI / Credit / Mixed payment mode
- Monthly totals: sales, received, pending, quantity
- CSV export and Android print dialog (where supported) to save/print PDF

Build APK:
1. Install Android Studio (recent stable version) on a computer.
2. Open this folder as an existing Android Studio project.
3. Allow Gradle sync and install the Android SDK Platform 35 if prompted.
4. Select Build > Build Bundle(s) / APK(s) > Build APK(s).
5. Android Studio will show the generated APK location.

Important:
- This is source project, not a prebuilt APK.
- Records are stored locally on this device/app. Uninstalling or clearing app data may erase them.
- Export CSV backups regularly.
- Test totals and PDF printing before using for official accounting.
